Installing

Run the setup and tick the apps you want. It installs for your Windows user, so no administrator rights are needed, and you can add the other apps later from the start page (Tools > Install Apps). The setup is not yet code-signed, so Windows may say it protected your PC: choose More info, then Run anyway.

Updates

Once installed, the suite's start page looks for updates when it opens. Each app with a newer version shows Update available and an Update button, and Update all brings the whole suite up to date. Your data file is backed up first.
