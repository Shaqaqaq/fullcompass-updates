# Full Compass Accountancy Suite: downloads and updates

This repository holds only the published release files for the Full Compass Accountancy Suite, served by GitHub
Pages at https://updates.fullcompass.co.uk/:

- `index.html`: the download page;
- `latest.json`: the signed list of each app's latest version, which installed copies check;
- `files/`: the installers and the one-file setup.

There is no source code here. Releases are made with the suite's `suite-release` tool and copied in with its
`publish.sh`.
